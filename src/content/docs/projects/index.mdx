## How Projects Are Engineered & Documented

```text
Each Project Directory
  ├── Overview (index.mdx)         → Business context, outcomes, single source of truth for tech stack
  ├── Architecture (architecture)  → Interactive Archify SVG/HTML diagram, trust boundaries, dataflow
  ├── Cheatsheet (cheatsheet)      → High-density commands, K8s snippets, env vars, emergency one-liners
  ├── Errors & Fixes (errors)      → Exact logs, misleading clues, RCA, code diffs, prevention rules
  └── Interview Prep (interview)   → System design questions, STAR behavioral proofs, edge cases
```

To create a new project following this exact specification, run:
```bash
npm run scaffold:project <project-slug> "Project Name"
```

Read the full specification in the [Project Documentation Standard](/project-standard/).
